# Solvers with one LLM idea each

Each folder is the seed solver plus one idea proposed by an inventor during run `p60`, exactly as the inventor
left it (the idea is a switch in `genes.json`, off by default). They are here because record sets were found
by searches that ran these solvers with the idea switched on, and a certificate should name code that can be
read. Finding a record in such a search does not show that the idea caused it: see RESULTS.md.
